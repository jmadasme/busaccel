# rec/ — video explicativo

Este directorio contiene el video asciinema de **BusAccel: golpes sobre ruedas** y el reproductor
que se usa en la página del proyecto.

- `busaccel.cast`: grabación original (asciicast v2).
- `busaccel.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:16. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
